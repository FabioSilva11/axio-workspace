================================================================================
MONITORAMENTO
================================================================================

Ver logs em tempo real:
   tools\monitorar_logs.bat

Ou com PowerShell:
   Get-Content traffic_log.txt -Wait -Tail 20

Ver ultimas 50 linhas:
   Get-Content traffic_log.txt -Tail 50

Buscar palavra nos logs:
   findstr "error" traffic_log.txt
   findstr "gemini" traffic_log.txt

================================================================================
ANALISE DE LOGS
================================================================================

Analise completa:
   powershell -ExecutionPolicy Bypass -File tools\analisar_logs.ps1

Ver estatisticas:
   - Total de requests/responses
   - Endpoints acessados
   - Status codes
   - Modelos utilizados
   - Uso de tokens
   - Mensagens enviadas
   - Erros detectados
   - Timeline

================================================================================
ADB (ANDROID DEBUG BRIDGE)
================================================================================

Listar dispositivos:
   adb devices

Listar apps instalados:
   adb shell pm list packages | findstr "axion"

Ver logs do app em tempo real:
   adb logcat | findstr "axion"

Limpar dados do app:
   adb shell pm clear com.saaspaymentsolutions.axion

Forcar parada do app:
   adb shell am force-stop com.saaspaymentsolutions.axion

Iniciar app:
   adb shell monkey -p com.saaspaymentsolutions.axion -c android.intent.category.LAUNCHER 1

Abrir configuracoes do app:
   adb shell am start -n com.saaspaymentsolutions.axion/.SettingsActivity

Ver memoria do app:
   adb shell dumpsys meminfo com.saaspaymentsolutions.axion

================================================================================
FIREWALL
================================================================================

Adicionar regra (como admin):
   netsh advfirewall firewall add rule name="Axion Proxy Server" dir=in action=allow protocol=TCP localport=8090

Ou execute:
   tools\abrir_firewall.bat (como administrador)

Verificar porta:
   netstat -ano | findstr :8090

================================================================================
REDE
================================================================================

Ver seu IP local:
   ipconfig | findstr "IPv4"

Testar conectividade do celular (ping):
   ping 192.168.1.68

Testar porta do celular (telnet):
   telnet 192.168.1.68 8090

Ou no navegador do celular:
   http://192.168.1.68:8090/health

================================================================================
TESTES MANUAIS
================================================================================

Testar modelos:
   curl -X GET http://127.0.0.1:8090/v1/models ^
        -H "Authorization: Bearer test-key-123"

Testar chat (sem streaming):
   curl -X POST http://127.0.0.1:8090/v1/chat/completions ^
        -H "Authorization: Bearer test-key-123" ^
        -H "Content-Type: application/json" ^
        -d "{\"model\":\"gemini-3-flash\",\"messages\":[{\"role\":\"user\",\"content\":\"Ola!\"}],\"max_tokens\":50}"

Testar com PowerShell:
   $headers = @{"Authorization"="Bearer test-key-123"; "Content-Type"="application/json"}
   $body = @{model="gemini-3-flash"; messages=@(@{role="user"; content="Teste"})} | ConvertTo-Json
   Invoke-RestMethod -Uri "http://127.0.0.1:8090/v1/chat/completions" -Method Post -Headers $headers -Body $body

TROUBLESHOOTING
================================================================================

Servidor nao inicia:

   python -m pip install requests

   Instalar: https://developer.android.com/studio/releases/platform-tools
   Adicionar ao PATH

Celular nao conecta:
   1. Mesma WiFi?
   2. Firewall aberto?
   3. Testar: curl http://192.168.1.68:8090/health

Logs vazios:
   1. App fazendo requisicoes?
   2. URL correta no app?
   3. API key correta?
